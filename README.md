# My Desktop ✿

หน้าเว็บเดสก์ท็อปสไตล์ Mac ที่รวมแอปเล็ก ๆ ไว้ในที่เดียว กดไอคอนบนเดสก์ท็อปหรือใน Dock เพื่อเปิดแต่ละแอปเป็นหน้าต่าง
ลากย้าย ปรับขนาด และขยายเต็มจอได้

## แอปข้างใน

| แอป | ทำอะไรได้ |
|---|---|
| 👤 **โปรไฟล์** | การ์ดโปรไฟล์ มีรูปสไลด์เปลี่ยนเองทุก 5 วินาที และปุ่มเปลี่ยนธีมสี 6 แบบ |
| 🧮 **Sakura Calc** | เครื่องคิดเลขวิทยาศาสตร์ ใช้คีย์บอร์ดได้ มีประวัติการคำนวณ |
| ⚖️ **BMI Calculator** | คำนวณดัชนีมวลกาย ผู้ใหญ่ใช้เกณฑ์คนเอเชีย เด็กและวัยรุ่น 5–17 ปีใช้ WHO Growth Reference 2007 แยกตามเพศและอายุ |

## วิธีเปิด

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## โครงสร้าง

```
index.html            ← เดสก์ท็อป (เมนูบาร์, Dock, ตัวจัดการหน้าต่าง)
apps/profile/         ← การ์ดโปรไฟล์ + รูป
apps/calculator/      ← เครื่องคิดเลข
apps/bmi/             ← คำนวณ BMI
```

ข้อมูลเกณฑ์ BMI ของเด็กมาจาก [WHO Growth Reference 5–19 years](https://www.who.int/tools/growth-reference-data-for-5to19-years/indicators/bmi-for-age)
